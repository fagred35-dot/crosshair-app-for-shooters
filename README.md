# AimPoint

Нативное приложение для Windows на C++: прозрачный прицел поверх игры, библиотека из **360 пресетов** и настраиваемый автокликер.

![C++20](https://img.shields.io/badge/C%2B%2B-20-4ee7a6) ![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-4b8cff) ![Dependencies](https://img.shields.io/badge/runtime-зависимостей%20нет-8b96a9)

## Возможности

### Прицел

- 360 уникальных процедурных пресетов: 12 форм × 10 цветовых схем × 3 режима анимации;
- 120 статичных и 240 анимированных вариантов;
- формы «Классика», «Точка», «Кольцо», T-прицел, «Шеврон», «Ромб», «Снайпер», «Крылья», «Триада» и другие;
- анимации «Пульс» и «Вращение»;
- размер 50–180%, прозрачность 20–100%, обводка и центральная точка;
- смещение центра по X/Y и автоматический выбор активного монитора;
- кликабельный прозрачный Win32-оверлей: он не забирает фокус и не блокирует мышь;
- `Ctrl + Shift + O` мгновенно скрывает/показывает прицел.

### Автокликер

- 1–30 кликов в секунду;
- регулируемый случайный разброс интервала;
- одиночные, двойные и тройные серии;
- левая или правая кнопка мыши;
- режимы «Переключатель» и «Удержание»;
- глобальная клавиша запуска `F6`–`F9`;
- аварийная остановка клавишей `Esc`;
- отправка обычных системных событий через `SendInput` — без внедрения DLL, чтения памяти или доступа к процессам игры.

### Интерфейс

- русскоязычная тёмная панель управления;
- фильтры галереи, анимированные превью и случайный выбор;
- сохранение всех параметров в `%APPDATA%\AimPoint\settings.ini`;
- сворачивание в область уведомлений;
- необязательный автозапуск с Windows без прав администратора.

## Сборка

Требования: Windows 10/11, CMake 3.20+ и Visual Studio 2022 с компонентом **Desktop development with C++**.

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Готовый файл: `build\Release\AimPoint.exe`.

Установка в отдельную папку:

```powershell
cmake --install build --config Release --prefix package
```

Проект не использует внешние библиотеки и менеджеры пакетов. Для проверки генератора каталога на любой платформе:

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

## Использование

1. Запустите `AimPoint.exe`.
2. В разделе **Галерея** выберите пресет; результат сразу появится в центре активного монитора.
3. Отрегулируйте размер, прозрачность и точку в разделе **Мой прицел**.
4. Если нужен автокликер, включите его, выберите режим и горячую клавишу. В режиме «Переключатель» одно нажатие запускает клики, второе останавливает. В режиме «Удержание» клики идут, пока клавиша нажата.
5. `Esc` всегда останавливает активный автокликер. Крестик сворачивает приложение в трей (это можно изменить в настройках).

## Важные замечания

- Оверлей рассчитан на оконный и безрамочный оконный режим. Эксклюзивный полноэкранный режим некоторых игр может скрывать любые обычные окна Windows.
- Некоторые игры и площадки запрещают сторонние оверлеи или автокликеры. Перед использованием проверьте правила проекта. AimPoint не обходит античит и не пытается скрыть свою работу.
- Если выбранная функциональная клавиша уже зарегистрирована другой программой, AimPoint покажет предупреждение; выберите другую клавишу.

## Структура

```text
src/CrosshairPreset.*    генератор 360 пресетов
src/CrosshairRenderer.*  отрисовка 12 форм и анимаций через GDI
src/OverlayWindow.*      прозрачное click-through окно
src/ClickerEngine.*      поток автокликера и аварийная остановка
src/MainWindow.*         кастомный интерфейс, трей и hotkeys
src/SettingsStore.*      INI-настройки и автозапуск
```
